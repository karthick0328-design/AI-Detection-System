About This Project

Methodology, Machine Learning Architecture, and Experimental Telemetry.

Project Overview

PhishingGuard AI is a machine learning security application designed to detect malicious websites before they compromise user credentials or data. By combining 18+ lexical URL features, real-time DNS resolution checks, and explainable AI transparency algorithms, the system provides sub-second threat scoring without downloading or executing untrusted remote code.

Key Features

ML-Based Detection
Random Forest classifier trained on 20,000+ benchmark URLs
Explainable AI (XAI)
SHAP-inspired feature contributions and structural breakdown
Domain Reputation Checks
Active DNS resolution, TLD validation, and heuristic rules
History & Analytics
Real-time SQLite telemetry with CSV and report exporting

Methodology & Pipeline Architecture

1

Data Collection

Benchmark URLs gathered from verified sources (PhishTank, OpenPhish, Alexa/Tranco).

2

Preprocessing

URL sanitization, punycode decoding, scheme parsing, and 18-signal lexical vector extraction.

3

Model Training

Stratified Random Forest ensemble trained with balanced class weights and cross-validation.

4

Evaluation

Rigorous testing on unseen targets measuring precision, recall, F1 score, and ROC-AUC curve.
