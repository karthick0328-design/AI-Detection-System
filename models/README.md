# Machine Learning Models Directory

This directory stores trained machine learning model artifacts generated by `src/train_model.py`:

- `phishing_detector_model.joblib`: The serialized scikit-learn model pipeline or estimator selected as the best performing model.
- `metadata.json`: Model version, training timestamp, chosen algorithm, hyperparameters, training dataset sample size, and random seed.
- `feature_names.json`: The exact list and order of feature names used during training and expected during inference.
- `evaluation_report.json`: Metrics measured on the held-out test set (Accuracy, Precision, Recall, F1-score, ROC-AUC, FPR, FNR, Confusion Matrix).
- `confusion_matrix.png`: Visual confusion matrix plot generated during evaluation.

## Note
Do not manually edit `feature_names.json` or `metadata.json`. They are produced deterministically during model training.
